# G.A.I. V2 ROADMAP — Capability Expansion

V2 begins only after V1 is released and the closed organism loop is proven. V2 is the capability layer built on top of the stable V1 body.

## V2 principle

V1 asks:
**Can G.A.I. reliably sense → attend → think → act → receive consequence → learn → remember → recover?**

V2 asks:
**Given that loop, what can G.A.I. learn to do that we did not explicitly script?**

Every V2 capability must remain inside the same organism loop:

Sense → Attend → Interpret → Remember → Predict → Want → Plan → Act → Consequence → Learn → Sleep → Change

## V2.0 — Learning

Focus:
- Neural Fabric 2.0 with richer sparse adaptive maps.
- Temporal associations and sequences.
- Context-dependent routes.
- Neural activation state and competition.
- Reward/prediction-error propagation.
- Habituation, novelty and forgetting.
- Stronger dream replay and consolidation.
- Neural ablation and causal-learning experiments.

Done when:
Experience can change relationships between experiences, not merely store them, while remaining bounded and measurable.

## V2.1 — World

Focus:
- Active perception and deliberate re-observation.
- Persistent object/world representations.
- Spatial awareness and relative location.
- Object history, affordances and predicted behaviour.
- Confidence and uncertainty-driven perception.
- Grounded perception/action experiments.

Done when:
G.A.I. can deliberately look/listen again when uncertain and maintain useful representations of persistent things.

## V2.2 — Self

Focus:
- Persistent self-model.
- Capability and limitation model.
- Autobiographical continuity.
- Confidence and uncertainty about its own knowledge.
- Functional affective state.
- Learned preferences and habits.

Done when:
G.A.I. can maintain an internally generated representation of its own state, capabilities, history and uncertainty without relying on a static personality prompt.

## V2.3 — Agency

Focus:
- Needs → drives → goals → subgoals.
- Multi-step planning with resource/action budgets.
- Strategy selection and revision.
- Curiosity and exploration.
- Internal hypothesis/experiment loop.
- Goal success/failure learning.

Done when:
G.A.I. can select and revise bounded multi-step strategies based on consequences rather than executing only immediate scripted intentions.

## V2.4 — Body & Tools

Focus:
- Richer digital organs and capability interfaces.
- Consistent organ discovery and capability contracts.
- More advanced manipulation of desktop/toy environments.
- Optional multi-camera/spatial sensing.
- Sandboxed external environments.
- Capability-specific learning.

Done when:
New tools can be added as organs without creating competing cognitive/control paths.

## V2.5 — Creation

Focus:
- Autonomous text creation.
- SVG/image/paint creation.
- Audio/music experimentation.
- Coding and simulation.
- Persistent creative portfolio.
- Create → inspect → self-critique → revise → reward loops.

Done when:
G.A.I. can initiate and complete bounded creative projects for internally generated reasons such as goals, curiosity or learned preference.

## V2.6 — Social

Focus:
- Interaction state and turn-taking.
- Shared goals.
- Collaboration and teaching/being taught.
- Long-term interaction continuity.
- Social attention and response quality.

Done when:
G.A.I. can model the current interaction sufficiently to collaborate rather than merely respond to isolated inputs.

## V2.7 — Evolutionary Sandbox

Late V2 research only:
- Sandboxed architectural experiments.
- Alternative neural structures.
- Behaviour/policy variants.
- Capability combinations.
- Automated testing and rollback.
- Experimental self-modification with human-controlled promotion.

Done when:
G.A.I. can safely experiment with bounded variants without modifying the production organism directly.

## Late V2 / V3 research

Keep these explicitly experimental:
- Multiple interacting cognitive processes.
- Rich artificial internal chemistry/dynamics.
- Large-scale evolutionary systems.
- Distributed/networked bodies.
- Major embodied-world environments.
- Any consciousness-related investigation.

## V2 guardrails

- V1 remains the stable base; do not destabilise it for V2 experiments.
- No direct model → hardware control.
- No hidden competing control loops.
- New organs use explicit contracts and health states.
- Self-modification stays sandboxed and reversible.
- Every major capability gets a deterministic experiment before being treated as real.
- Prefer bounded learning and useful behaviour over larger models or higher compute.
