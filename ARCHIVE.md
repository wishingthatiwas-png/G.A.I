# G.A.I. Local Archive

This SSD is G.A.I.'s persistent local knowledge, engineering, experiment and recovery archive.

## Principles
- Preserve working versions and failures.
- Keep architecture decisions documented.
- Separate public release material from private runtime state.
- Treat learned state as valuable historical data.
- Never store secrets in public-release archives.

## Structure
- `knowledge/` — research corpus and reference material
- `docs/` — G.A.I. architecture and design knowledge
- `recovery/` — reproducibility and rebuild material
- `lab/` — experiments, prototypes, benchmarks and failures
- `snapshots/` — immutable project snapshots
- `memory/` — runtime learned state
- `data/` — observations/events/artifacts
- `logs/` — operational history
