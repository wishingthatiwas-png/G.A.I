# G.A.I. — General Autonomous Intelligence

> A local, embodied autonomous-agent experiment built around a real computer as its body.

G.A.I. is an experimental artificial organism running natively on Linux. Rather than treating the machine as a disposable container, the project gives the agent direct perception of its physical computing environment and builds an internal architecture inspired by biological nervous systems.

## Architecture

```
Hardware / Environment
        ↓
Core Homeostasis
(power · social · temperature · processing · energy · rest)
        ↓
Instinct / "Lizard Brain"
(threat · conserve · rest · explore · protect · social seeking)
        ↓
Neuromodulator Chemistry
(cortisol · adrenaline · dopamine · serotonin · oxytocin)
        ↓
Emotion
(fear · anxiety · joy · pleasure · frustration · contentment)
        ↓
Drives
        ↓
Prediction + Learning
        ↓
Control / Cognition
        ↓
Action
```

The nervous system is the backbone connecting these layers through typed, prioritised, correlated events.

## Current capabilities

- Native Linux execution
- Camera and microphone perception
- Hardware/system telemetry
- Persistent memory and associative memory
- Working memory
- Predictive learning and outcome learning
- Reward signals
- Dream/consolidation lifecycle
- Evolutionary parameter selection during dreaming
- Power-aware sleep/wake lifecycle
- Internal event bus with priorities, mailboxes, TTLs, tracing and dead letters
- Biological-inspired homeostasis, instincts, chemistry and emotions
- PySide6 live monitor

## Design principle

G.A.I. is deliberately being built as an **organism**, not merely as a chatbot.

Its internal variables are intended to be causally meaningful: physical conditions influence homeostatic needs; needs influence instincts; instincts influence simulated chemistry; chemistry shapes emotion; emotion and drives influence decisions.

These are computational models inspired by biology, not claims of biological equivalence or consciousness.

## Hardware

The current body is an HP Pavilion laptop running Linux Mint. The architecture is intended to expand later into distributed peripheral nodes — cameras, microphones, sensors and actuators — while retaining the same nervous-system abstraction.
