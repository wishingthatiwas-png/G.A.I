# G.A.I.

Local autonomous agent workspace.

## Layout
- `agent/` — agent source
- `config/` — configuration
- `state/` — runtime state
- `runtime/` — transient runtime files
- `data/` — persistent data
- `memory/` — memory stores
- `models/` — model assets
- `logs/` — logs
- `projects/` — experiments/projects
- `venvs/` — isolated Python environments
- `scripts/` — system/setup helpers
