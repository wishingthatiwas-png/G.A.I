# Deep Memory Format

A long-term memory is a compact reconstruction recipe rather than a raw image by default.

Suggested fields:
- memory_id
- timestamp / approximate age
- scene graph / words / shapes / spatial relationships
- entities and properties
- emotional/instinctive context
- importance/salience
- confidence
- source/provenance
- reconstruction version
- associations to other memories

Raw sensory media can remain on SSD or be separately archived; the default long-term representation should be small, symbolic and reconstructable.
